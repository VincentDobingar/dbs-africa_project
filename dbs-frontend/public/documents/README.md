# Documents téléchargeables — Programme Partenaires

PDF générés à partir du contenu fourni (brochure + guide), en français et en anglais.
Le lien de téléchargement sur `/partner` choisit automatiquement la version correspondant
à la langue active du site (FR/EN).

- `dbs-africa-brochure-partenaire-fr.pdf` / `dbs-africa-brochure-partenaire-en.pdf`
- `dbs-africa-guide-partenaire-fr.pdf` / `dbs-africa-guide-partenaire-en.pdf`

Pour mettre à jour le contenu : modifier les sources (non versionnées, générées via HTML → PDF)
et régénérer, ou remplacer directement ces fichiers par une version plus officielle si disponible.
